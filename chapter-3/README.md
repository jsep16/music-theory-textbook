# Chapter 3 · Intervals

Buildless HTML/CSS/JavaScript chapter for GitHub Pages. Published beneath `chapter-3/` in `jsep16/music-theory-textbook`, alongside the existing Chapter 2 at the repository root.

- All approved chapter text, both source tables, and all 14 recordings are included.
- Recording 54 appears twice to match the chapter. One audio player plays at a time.
- The F4 overview, 20 interval-identification questions, and 20 interval-construction questions use the finished PDF's musical content.
- Identification accepts full names or case-sensitive abbreviations such as M2 and m2. Construction checks letter, accidental, and octave; enharmonic substitutions do not count as the same spelling.
- Students may use keyboard-accessible note controls or click the staff to select letter and octave.
- Responses exist only in the current page. Reloading clears them; nothing is submitted or stored.
- The final student PDF is included. The separate instructor answer PDF is excluded. Local answer-checking rules are readable in the public source.
- musictheory.net links open visual and aural exercises in separate tabs.

Open `index.html` using a static server or the published URL. No build step or package installation is required.

Validation: all 40 interval spellings and sizes checked independently; answer aliases, negative cases, and staff-coordinate round trips tested; all local paths, tables, audio hashes, and student PDF checked. Browser checks passed for all 40 correct responses, wrong quality and wrong octave responses, staff-click placement, playback initiation, desktop and phone layouts, and navigation between Chapters 2 and 3.
